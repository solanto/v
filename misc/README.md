# v branding

## developing

All textual glyphs are derived from [STIX Two Text](https://www.stixfonts.org/).

Source assets (`.src.svg`) are created in [Boxy SVG](https://boxy-svg.com/), with occasional help from [Inkscape](https://inkscape.org/) to turn complex objects into paths.

After exporting from source, they are minified with [SVGO](https://svgo.dev/) (for example, via [Oh My SVG](https://github.com/sonnyp/OhMySVG)).
